## 📄 Job Post's - Dream Technolabs
## 📌 Overview
A vintage, typewriter-styled career page template built with HTML and CSS, designed to resemble an old physical letter with realistic details like coffee stains, a paper clip, and custom stamps.

---

## ✨ Features
* **Vintage Paper Aesthetic:** Styled with custom background gradients, ink-bleed text shadows, and the classic typewriter font (`Special Elite`).
* **Skeuomorphic Visuals:** Includes simulated physical elements like a paper clip, a coffee ring stain, and custom company stamps.
* **Open Roles List:** Highlights current job openings ranging from technical database and development roles to marketing and content positions.
* **Direct Call to Action:** Features a styled email application button pre-configured with the HR contact email and a dynamic subject line template.

---

## 🚀 Getting Started
1. Save the HTML code into a file named `index.html`.
2. Ensure you have the required assets in your directory (e.g., the stamp image referenced as `a.png`).
3. Open `index.html` in any modern web browser to view the vintage letter design.
